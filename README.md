Reisleiders – Webbased Digitale Toolkit (Prototype)

Dit project bevat een webbased prototype van een digitale toolkit voor Reisleiders. Het prototype is ontwikkeld om gebruikers te ondersteunen bij het snel en zelfstandig vinden van materialen en het communiceren binnen de organisatie. De focus ligt op gebruiksvriendelijkheid, overzicht en zelfstandigheid.

Het prototype is ontwikkeld als Proof of Concept (POC) en bevat geen backend-functionaliteiten.

Doel van het prototype
Het doel van dit prototype is het verkennen en testen van:

een centrale, overzichtelijke digitale omgeving voor materialen

eenvoudige en zelfstandige communicatie tussen gebruikers

een intuïtieve navigatiestructuur die minimale uitleg vereist

De bijbehorende doelen en KPI’s zijn getest tijdens gebruikerstesten.

Gebruikte technologieën

React – component-based front-end ontwikkeling

Next.js – routing en projectstructuur

Tailwind CSS – styling via utility-first classes

Node.js – runtime-omgeving

Git – versiebeheer

Er wordt geen gebruikgemaakt van externe API’s, databases of hardware.

Projectstructuur

Het project maakt gebruik van de file-based routing van Next.js. Elke pagina is ondergebracht in een eigen map met een page.js bestand. Herbruikbare UI-elementen zijn uitgewerkt als losse React-componenten.
